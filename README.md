# VueApexCharts

Detta är ett projekt för en sida som visar olika grafer med hjälp av Apexcharts. Jag gav upp på att få router att funka så man navigerar mellan olika vyer med en enkel knapp.

För att installera projektet, ladda ner hela projektet från gitHub och installera npm med "npm install". Kör sen "npm run dev" och öppna localhost på rätt port.
